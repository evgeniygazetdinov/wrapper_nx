# Структура файлов данных Bully

## 📦 Источники данных

### 1. split_data_1.apk
Содержит два больших ZIP архива:
- `assets/data_0.zip` (~168MB) - основные игровые данные
- `assets/data_1.zip` (~825MB) - дополнительные данные (речь, текстуры)

### 2. base.apk
Содержит:
- `assets/flutter_assets/` - ресурсы Flutter UI
- `assets/rockstar/lang/` - языковые файлы
- `assets/movies/` - видео файлы

## ✅ Обязательные файлы для check_data()

Функция `check_data()` в `main.c` проверяет:

1. **bullyorig/** - основная папка данных
2. **bullyorig/version.cfg** - файл версии
3. **bullyorig/runtime.xml** - настройки времени выполнения
4. **bullyorig/memory.xml** - настройки памяти
5. **bullyorig/config/** - папка конфигурации
6. **bullyorig/models/** - папка моделей
7. **bullyorig/audio/** - папка аудио
8. **bullyorig/data/** - папка данных
9. **bully/** - дополнительная папка данных

## 📝 Инструкция по установке данных

### Вариант 1: Использование готового скрипта (рекомендуется)

Используйте скрипт `extract_bully_data.sh`:

```bash
# Извлечь данные в текущую папку
./extract_bully_data.sh

# Или указать целевую папку
./extract_bully_data.sh /path/to/game/
```

Скрипт автоматически:
1. Распакует `split_data_1.apk`
2. Распакует `data_0.zip` (создаст `bullyorig/`)
3. Распакует `data_1.zip` (создаст `bully/`)

### Вариант 2: Ручное извлечение

1. **Распакуйте split_data_1.apk:**
   ```bash
   cd /home/ev/Downloads/bully_archive/Bully_v1.4.277.build.3793806
   unzip split_data_1.apk -d /tmp/bully_extract/
   ```

2. **Распакуйте data_0.zip:**
   ```bash
   unzip /tmp/bully_extract/assets/data_0.zip -d /path/to/game/
   ```
   Это создаст папку `bullyorig/` в корне игры.

3. **Распакуйте data_1.zip:**
   ```bash
   unzip /tmp/bully_extract/assets/data_1.zip -d /path/to/game/
   ```
   Это создаст папку `bully/` в корне игры.

4. **Структура должна быть:**
   ```
   /path/to/game/
   ├── libGame.so
   ├── project.nro
   ├── config.txt
   ├── bullyorig/
   │   ├── version.cfg
   │   ├── runtime.xml
   │   ├── memory.xml
   │   ├── config/
   │   ├── models/
   │   ├── audio/
   │   └── ...
   └── bully/
       ├── speech_*.snd
       ├── *.tex
       └── ...
   ```

## ⚠️ Важные замечания

1. **Размер данных:** Общий размер данных около 1GB, убедитесь, что на SD карте достаточно места.

2. **Пути:** Файлы должны быть в корне папки игры, не во вложенных папках.

3. **Права доступа:** Убедитесь, что файлы имеют правильные права доступа (чтение).

4. **Опциональные файлы:** Некоторые файлы могут быть опциональными:
   - `jumptable.bin` - может быть не обязательным
   - `bs-checkpoint.dat` - может быть не обязательным
   - Некоторые подпапки могут быть опциональными

5. **Тестирование:** Если игра не запускается, попробуйте:
   - Убрать некоторые проверки из `check_data()`
   - Проверить логи ошибок
   - Убедиться, что все файлы распакованы правильно

## 🔍 Дополнительная информация

- **data_0.zip** содержит основные игровые данные (модели, конфиги, аудио банки)
- **data_1.zip** содержит большие файлы (речь, текстуры, музыка)
- Оба архива должны быть распакованы для полноценной работы игры
