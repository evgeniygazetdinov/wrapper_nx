# Инструкция по сборке для Switch

## 🚀 Быстрая сборка

Используйте скрипт `build_for_switch.sh` для автоматической сборки:

```bash
./build_for_switch.sh
```

Это создаст папку `switch_bully_ready/` со всеми необходимыми файлами.

## 📋 Что делает скрипт

1. ✅ Собирает проект (`make clean && make`)
2. ✅ Проверяет наличие `libGame.so`
3. ✅ Извлекает данные игры (если нужно)
4. ✅ Копирует все файлы в выходную папку
5. ✅ Проверяет структуру
6. ✅ Создает README.txt
7. ✅ Опционально создает ZIP архив

## 💻 Варианты использования

### Базовое использование
```bash
./build_for_switch.sh
```
Создаст папку `./switch_bully_ready/`

### С указанием выходной папки
```bash
./build_for_switch.sh ./my_switch_folder
```

### С указанием папки с данными
```bash
./build_for_switch.sh ./ready ./bully_data
```

### С созданием ZIP архива
```bash
./build_for_switch.sh ./ready ./bully_data --zip
```

### Справка
```bash
./build_for_switch.sh --help
```

## 📦 Что будет в выходной папке

```
switch_bully_ready/
├── project.nro          # Скомпилированный wrapper
├── libGame.so           # Библиотека игры
├── config.txt           # Конфигурация (если есть)
├── README.txt           # Инструкция по установке
├── bullyorig/           # Основные данные игры
└── bully/              # Дополнительные данные
```

## 📤 Отправка на Switch

1. **Скопируйте содержимое папки на SD карту:**
   ```bash
   # Скопируйте ВСЁ содержимое папки switch_bully_ready/
   # в папку SD:/switch/bully/
   ```

2. **Структура на Switch должна быть:**
   ```
   SD:/switch/bully/
   ├── project.nro
   ├── libGame.so
   ├── bullyorig/
   └── bully/
   ```

3. **Запустите через Homebrew Menu**

## ⚙️ Требования

- `make` и devkitA64 для сборки проекта
- `libGame.so` в папке проекта (или будет найден автоматически)
- Данные игры (будут извлечены автоматически, если нужно)

## 🔍 Проверка перед отправкой

Скрипт автоматически проверяет:
- ✅ Наличие `project.nro`
- ✅ Наличие `libGame.so`
- ✅ Наличие `bullyorig/version.cfg`
- ✅ Наличие `bullyorig/runtime.xml`
- ✅ Наличие основных папок

## 📊 Размеры

После сборки вы увидите:
- Размер каждого компонента
- Общий размер папки
- Размер архива (если создан)

## 🐛 Решение проблем

### Ошибка сборки
```bash
# Убедитесь, что devkitA64 установлен
# Проверьте переменную DEVKITPRO
echo $DEVKITPRO
```

### libGame.so не найден
```bash
# Скопируйте вручную:
cp /path/to/libGame.so ./
```

### Данные не извлекаются
```bash
# Извлеките вручную:
./extract_bully_data.sh ./bully_data
```

## 📝 Пример полного процесса

# 1. Сборка

ls -lh ./ready/

# 3. Копирование на SD карту
# (вручную через файловый менеджер или команду cp)
